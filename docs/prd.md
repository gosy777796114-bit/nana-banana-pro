# وثيقة المتطلبات

## 1. نظرة عامة على التطبيق

### 1.1 اسم التطبيق
تطبيق نانه وبنانه برو - ابو القيس

### 1.2 وصف التطبيق
تطبيق ويب عربي احترافي لتوليد الصور باستخدام الذكاء الاصطناعي، يتيح للمستخدمين رفع صور مرجعية وإدخال نصوص وصفية وتخصيص إعدادات الصورة للحصول على صور مولدة بجودة عالية. يتضمن التطبيق تبويباً خاصاً لتوليد صور زووم الأقمشة. يدعم التطبيق رفع ملفات ضخمة حتى 1GB مع آليات حماية الذاكرة، ويوفر معلومات شفافة عن جودة الصور الناتجة.

## 2. المستخدمون وسيناريوهات الاستخدام

### 2.1 المستخدمون المستهدفون
- مستخدمون يرغبون في توليد صور باستخدام الذكاء الاصطناعي
- مستخدمون يحتاجون إلى إنشاء صور بمواصفات محددة
- مستخدمون يحتاجون إلى توليد صور زووم للأقمشة بتخطيطات مختلفة
- مستخدمون يعملون مع ملفات صور كبيرة الحجم

### 2.2 سيناريوهات الاستخدام الأساسية
- رفع صور مرجعية واستخدامها كسياق للتوليد
- كتابة وحفظ وإدارة نصوص وصفية للتوليد
- تخصيص أبعاد وجودة الصور المولدة
- توليد صور وتنزيلها
- رفع صورة قماش وتوليد صور زووم بتخطيطات متعددة
- رفع ملفات صور ضخمة حتى 1GB بشكل آمن
- التحقق من جودة الصور الناتجة ومطابقتها للمواصفات المطلوبة

## 3. هيكل الصفحات ووصف الوظائف

### 3.1 هيكل الصفحات
```
├── الصفحة الرئيسية
    ├── التبويب الأول: توليد الصور الأساسي
    │   ├── لوحة الكشف عن المشاكل
    │   ├── قسم رفع الصور المرجعية
    │   ├── قسم إدخال البرومبت
    │   ├── مدير البرومبتات المحفوظة (لوحة جانبية)
    │   ├── قسم إعدادات الصورة
    │   ├── شريط تقدم التوليد
    │   └── قسم نتيجة التوليد
    └── التبويب الثاني: زوم الأقمشة
        ├── أزرار رأس التبويب
        ├── قسم رفع صورة القماش
        ├── قسم اختيار عدد الصور المصغرة
        ├── قسم إعدادات نسب الزووم
        ├── قسم اختيار قالب التخطيط
        ├── أزرار التوليد وإنشاء البرومبت
        ├── شريط تقدم التوليد
        └── قسم نتيجة التوليد
```

### 3.2 التبويب الأول: توليد الصور الأساسي

#### 3.2.1 لوحة الكشف عن المشاكل
- عرض دائم في أعلى الصفحة
- قابلة للطي والتوسيع
- عرض المعلومات التشخيصية:
  - حالة اتصال API (مؤشر أخضر للنجاح، أحمر للفشل)
  - عدد الصور المرجعية المحملة
  - عدد أحرف البرومبت الحالي
  - الأبعاد والجودة المحددة
  - آخر رسالة خطأ مع التفاصيل التقنية
  - رقم محاولة التوليد
  - تحذيرات حول أحجام الملفات أو التنسيقات
  - سجلات مستوى Console
  - مقارنة الأبعاد المطلوبة مقابل الأبعاد الفعلية للصورة الناتجة

#### 3.2.2 قسم رفع الصور المرجعية
- منطقة رفع بنظام السحب والإفلات
- قبول جميع تنسيقات الصور: JPG, PNG, WebP, HEIC, RAW, TIFF, BMP, GIF, SVG وأي تنسيق آخر
- قبول صور بأي حجم بما في ذلك الملفات الأكبر من 1GB
- استخدام createImageBitmap API للملفات الأكبر من 50MB لتجنب انهيار المتصفح
- عرض شريط تقدم الرفع لكل صورة
- بعد الرفع، عرض الصور في شبكة مرقمة (1، 2، 3...)
- كل صورة تعرض: رقم، اسم الملف، حجم الملف، صورة مصغرة، زر حذف
- السماح برفع عدد غير محدود من الصور
- جميع الصور المرفوعة تُرسل إلى Nano Banana Pro كسياق

#### 3.2.3 قسم إدخال البرومبت
- منطقة نصية تقبل حتى 10,000 حرف
- عداد حي يعرض الأحرف المتبقية بصيغة \"X / 10,000 حرف\"
- زر \"حفظ البرومبت\": حفظ النص الحالي باسم مخصص يدخله المستخدم
- زر \"البرومبتات المحفوظة\": فتح مدير البرومبتات المحفوظة

#### 3.2.4 مدير البرومبتات المحفوظة
- يفتح كلوحة جانبية من الجهة اليمنى
- خانة بحث في الأعلى لتصفية البرومبتات
- عرض جميع البرومبتات المحفوظة مع:
  - اسم البرومبت
  - أول 100 حرف من النص
- لكل برومبت ثلاثة أزرار:
  - \"تنزيل البرومبت\": تحميل البرومبت في منطقة النص الرئيسية
  - \"تعديل\": تعديل اسم أو نص البرومبت
  - \"حذف\": حذف البرومبت مع نافذة تأكيد
- البرومبتات مخزنة في localStorage

#### 3.2.5 قسم إعدادات الصورة
- محدد الأبعاد مع الخيارات:
  - مربع (1:1) - 1024×1024
  - أفقي (16:9) - 1920×1080
  - عمودي (9:16) - 1080×1920
  - أفقي (4:3) - 1440×1080
  - عمودي (3:4) - 1080×1440
  - بانورامي (21:9) - 2560×1080
  - مخصص: إدخال أبعاد دقيقة (العرض × الارتفاع)
- محدد الجودة مع الخيارات:
  - 2K (2048px)
  - 4K (4096px)
  - 8K (8192px)
  - 16K (16384px)
- هذه الإعدادات تُطبق فعلياً في معلمات استدعاء API

#### 3.2.6 شريط تقدم التوليد
- يظهر في أسفل الشاشة أثناء التوليد فقط
- عرض الوقت المنقضي بالثواني: \"الوقت المنقضي: 00:45\"
- عرض الوقت المتبقي المقدر: \"الوقت المتبقي: ~01:15\"
- شريط تقدم متحرك مع نسبة مئوية
- نص حالة يعرض الخطوة الحالية:
  - \"جاري إرسال الصور المرجعية...\"
  - \"جاري التوليد...\"
  - \"جاري المعالجة النهائية...\"

#### 3.2.7 قسم نتيجة التوليد
- عرض الصورة المولدة بالجودة الكاملة
- عرض إجمالي وقت التوليد: \"استغرق التوليد: 2 دقيقة و 34 ثانية\"
- عرض تفاصيل الصورة:
  - الأبعاد المطلوبة
  - الأبعاد الفعلية للصورة الناتجة (actualWidth × actualHeight)
  - مؤشر مطابقة الأبعاد (مطابق / غير مطابق)
  - حجم الملف
  - مستوى الجودة
- ثلاثة أزرار:
  - \"تنزيل الصورة\": تحميل الصورة بالجودة الكاملة
  - \"إعادة التوليد\": إعادة التوليد بنفس الإعدادات والبرومبت
  - \"البدء من جديد\": مسح كل شيء مع نافذة تأكيد

### 3.3 التبويب الثاني: زوم الأقمشة

#### 3.3.1 أزرار رأس التبويب
- زر \"بدء من جديد\": مسح جميع الحقول والإعدادات في هذا التبويب فقط
- زر \"تعليمات المبرمج\": عرض سجل تطوير هذا التبويب (البرومبت الأصلي + الرسائل اللاحقة)، مع زر نسخ كل النصوص وزر تصدير PDF
- زر \"كاشف الأخطاء\": مراقب أخطاء خاص بهذا التبويب يعرض اسم التبويب + تفاصيل الخطأ + وقته بصيغة قابلة للنسخ

#### 3.3.2 قسم رفع صورة القماش
- منطقة رفع بنظام السحب والإفلات + زر اختيار ملف
- قبول صورة واحدة فقط
- قبول جميع تنسيقات الصور
- دعم ملفات حتى 1GB
- استخدام createImageBitmap API للملفات الأكبر من 50MB
- تطبيق حد أقصى للبكسلات (MAX_CANVAS_PX) لحماية ذاكرة Canvas
- معاينة فورية للصورة المرفوعة
- عرض اسم الملف وحجمه
- زر حذف لإزالة الصورة

#### 3.3.3 قسم اختيار عدد الصور المصغرة
- حقل إدخال رقمي أو منزلق لاختيار عدد الصور المصغرة
- النطاق: من 1 إلى 6 صور
- القيمة الافتراضية: 4 صور

#### 3.3.4 قسم إعدادات نسب الزووم
- توليد حقول نسب الزووم ديناميكياً بناءً على العدد المختار
- لكل صورة مصغرة:
  - تسمية واضحة: \"نسبة الزووم للصورة المصغرة 1\"
  - حقل إدخال رقمي لنسبة الزووم بالنسبة المئوية
  - القيمة الافتراضية قابلة للتعديل

#### 3.3.5 قسم اختيار قالب التخطيط
- عرض 6 قوالب تخطيط بصرياً بأسلوب Wireframe:
  1. الصورة الكبيرة في المنتصف + الصور المصغرة محيطة
  2. الصورة الكبيرة يسار + الصور المصغرة عمودياً يمين
  3. الصورة الكبيرة يمين + الصور المصغرة يسار
  4. الصورة الكبيرة أعلى + شريط صور أسفل
  5. شبكة متساوية Grid
  6. قالب هرمي Pyramid
- كل قالب قابل للنقر للاختيار
- عرض إطار حول القالب المختار

#### 3.3.6 أزرار التوليد وإنشاء البرومبت
- زر \"إنشاء برومبت نصي\": ينشئ برومبت نصي تفصيلي بالإنجليزية يتضمن:
  - نسب الزووم لكل صورة مصغرة
  - القالب المختار
  - عدد الصور المصغرة
  - تعليمات صارمة: عدم تعديل النقشة أو الألوان أو الخامة
  - كل صورة مصغرة = زووم حقيقي وأمين من نفس القماش
  - الصورة الكبيرة مطابقة 100% للأصل
  - كلمة \"Zoom\" بالإنجليزي في كل إطار صورة مصغرة
  - عرض البرومبت في نافذة منبثقة مع زر نسخ
- زر \"توليد الصورة\": استخدام نفس آلية توليد الصور الموجودة (submitGenerationTask من imageGeneration.ts)

#### 3.3.7 شريط تقدم التوليد
- يظهر أثناء التوليد فقط
- عرض الوقت المنقضي بالثواني
- عرض الوقت المتبقي المقدر
- شريط تقدم متحرك مع نسبة مئوية
- نص حالة يعرض الخطوة الحالية

#### 3.3.8 قسم نتيجة التوليد
- عرض الصورة المولدة بالجودة الكاملة
- عرض إجمالي وقت التوليد
- عرض الأبعاد الفعلية للصورة الناتجة مقارنةً بالأبعاد المطلوبة
- زر \"تحميل\": تحميل الصورة باستخدام fetch-blob pattern

## 4. القواعد والمنطق التجاري

### 4.1 قواعد التبويب الأول

#### 4.1.1 قواعد رفع الصور
- قبول جميع تنسيقات الصور دون استثناء
- قبول أي حجم ملف بما في ذلك الملفات الأكبر من 1GB
- للملفات الأكبر من 50MB: استخدام createImageBitmap API بدلاً من الطريقة التقليدية لتجنب انهيار المتصفح
- ترقيم الصور حسب ترتيب الرفع
- جميع الصور المرفوعة تُرسل إلى مهارة Nano Banana Pro Image Generation كسياق

#### 4.1.2 قواعد إدارة البرومبتات
- الحد الأقصى لطول البرومبت: 10,000 حرف
- البرومبتات المحفوظة تُخزن في localStorage
- البحث في البرومبتات يتم بناءً على الاسم والنص
- عند تنزيل برومبت، يُحمل في منطقة النص الرئيسية

#### 4.1.3 قواعد إعدادات الصورة
- الأبعاد والجودة المحددة تُطبق فعلياً في معلمات استدعاء API
- عند اختيار \"مخصص\"، يجب إدخال العرض والارتفاع

#### 4.1.4 قواعد التوليد
- استخدام مهارة Nano Banana Pro Image Generation (image-generation) كمحرك التوليد الوحيد
- تمرير جميع الصور المرجعية والبرومبت والإعدادات إلى المهارة
- عرض شريط التقدم أثناء التوليد
- حساب الوقت المنقضي والمتبقي

#### 4.1.5 قواعد معالجة الصور الناتجة
- Edge Function (image-generation-query) يُعيد الأبعاد الفعلية للصورة الناتجة (actualWidth, actualHeight) في الاستجابة
- فحص حجم base64 قبل عملية atob: إذا تجاوز 4MB، إعادة الصورة كـ data URL مباشرةً لتجنب OOM
- صفحة النتيجة تعرض الأبعاد الفعلية مقارنةً بالأبعاد المطلوبة
- DiagnosticsPanel يُسجّل مقارنة الأبعاد في كل عملية توليد

#### 4.1.6 قواعد البدء من جديد
- عند النقر على \"البدء من جديد\"، عرض نافذة تأكيد
- بعد التأكيد، مسح:
  - جميع الصور المرفوعة
  - نص البرومبت الحالي
  - الإعدادات المحددة
  - نتيجة التوليد

### 4.2 قواعد التبويب الثاني: زوم الأقمشة

#### 4.2.1 قواعد رفع صورة القماش
- قبول صورة واحدة فقط في كل مرة
- عند رفع صورة جديدة، استبدال الصورة السابقة
- قبول جميع تنسيقات الصور
- دعم ملفات حتى 1GB
- للملفات الأكبر من 50MB: استخدام createImageBitmap API
- تطبيق حد أقصى للبكسلات (MAX_CANVAS_PX) لحماية ذاكرة Canvas ومنع استنزاف الذاكرة

#### 4.2.2 قواعد عدد الصور المصغرة
- النطاق المسموح: 1-6 صور
- عند تغيير العدد، إعادة توليد حقول نسب الزووم ديناميكياً

#### 4.2.3 قواعد نسب الزووم
- كل صورة مصغرة يجب أن يكون لها نسبة زووم محددة
- نسب الزووم تُدخل بالنسبة المئوية
- القيم الافتراضية قابلة للتعديل من قبل المستخدم

#### 4.2.4 قواعد قالب التخطيط
- يجب اختيار قالب واحد قبل التوليد
- القالب المختار يُطبق على الصورة المولدة

#### 4.2.5 قواعد إنشاء البرومبت النصي
- البرومبت يُنشأ بالإنجليزية
- يتضمن جميع الإعدادات المحددة
- يتضمن تعليمات صارمة:
  - عدم تعديل النقشة أو الألوان أو الخامة
  - كل صورة مصغرة = زووم حقيقي وأمين من نفس القماش
  - الصورة الكبيرة مطابقة 100% للأصل
  - كلمة \"Zoom\" بالإنجليزي في كل إطار صورة مصغرة

#### 4.2.6 قواعد التوليد
- استخدام نفس آلية توليد الصور الموجودة (submitGenerationTask من imageGeneration.ts)
- تمرير صورة القماش والبرومبت المُنشأ إلى المهارة
- عرض شريط التقدم أثناء التوليد
- عرض الأبعاد الفعلية للصورة الناتجة مقارنةً بالأبعاد المطلوبة

#### 4.2.7 قواعد البدء من جديد
- مسح جميع الحقول والإعدادات في هذا التبويب فقط
- لا يؤثر على التبويبات الأخرى

#### 4.2.8 قواعد الاستقلالية
- هذا التبويب مستقل تماماً عن التبويب الأول
- لا يشارك البيانات أو الإعدادات مع التبويبات الأخرى
- له كاشف أخطاء خاص به
- له سجل تطوير خاص به

### 4.3 قواعد حماية الذاكرة والاستقرار

#### 4.3.1 معالجة الملفات الضخمة
- الملفات الأكبر من 50MB: استخدام createImageBitmap API بدلاً من الطرق التقليدية
- تطبيق حد أقصى للبكسلات في Canvas لمنع استنزاف الذاكرة
- Edge Function يفحص حجم base64 قبل المعالجة: إذا تجاوز 4MB، إعادة data URL مباشرةً

#### 4.3.2 التحقق من الجودة
- Edge Function يُعيد الأبعاد الفعلية (actualWidth, actualHeight) في كل استجابة
- صفحات النتيجة تعرض مقارنة بين الأبعاد المطلوبة والفعلية
- DiagnosticsPanel يُسجّل مقارنة الأبعاد في كل عملية توليد

## 6. معايير القبول

### 6.1 التبويب الأول
1. المستخدم يفتح التطبيق ويرى اسم \"تطبيق نانه وبنانه برو - ابو القيس\" معروضاً بشكل بارز
2. المستخدم يرفع صورة مرجعية بحجم 800MB بنجاح دون انهيار المتصفح
3. المستخدم يكتب نص برومبت ويختار أبعاد وجودة الصورة
4. المستخدم ينقر على زر التوليد ويرى شريط التقدم
5. المستخدم يرى الصورة المولدة مع عرض الأبعاد الفعلية مقارنةً بالأبعاد المطلوبة
6. المستخدم يرى في لوحة التشخيصات مقارنة الأبعاد المطلوبة مقابل الفعلية
7. المستخدم ينقر على \"تنزيل الصورة\" ويحصل على الصورة بالجودة الكاملة

### 6.2 التبويب الثاني: زوم الأقمشة
1. المستخدم ينتقل إلى تبويب \"زوم الأقمشة\" ويرى واجهة مستقلة
2. المستخدم يرفع صورة قماش بحجم 600MB بنجاح دون استنزاف ذاكرة Canvas
3. المستخدم يختار عدد الصور المصغرة ويعدل نسب الزووم
4. المستخدم يختار قالب تخطيط من القوالب الستة
5. المستخدم ينقر على \"إنشاء برومبت نصي\" ويرى البرومبت التفصيلي
6. المستخدم ينقر على \"توليد الصورة\" ويرى شريط التقدم
7. المستخدم يرى الصورة المولدة مع عرض الأبعاد الفعلية مقارنةً بالأبعاد المطلوبة
8. المستخدم يحمل الصورة بنجاح
